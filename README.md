# Standpunktprotokoll

Застосунок для ведення польових геодезичних протоколів: станції, цільові пункти, висоти, призми та експорт PDF.

**Відкрити застосунок:** https://standpunktprotokoll-de.lonesinner.chatgpt.site

Автор: Oleksii Yermakov.

## Можливості

- Німецька, англійська, іспанська, італійська й українська мови.
- Станції та цільові пункти, повторне використання введених точок і висот.
- Типи GVP, BGVP, BVP, GKP, SP, PS0–PS3; взаємовиключні позначки RB/AP.
- Вибір призм із константами Leica.
- PDF A4 в альбомній орієнтації, локалізована легенда, час і погодні дані для аркушів.
- Темна та світла теми, встановлення як PWA, кешування для роботи без мережі.
- Локальне збереження, резервне копіювання й відновлення протоколів.

## Запуск розробки

Рекомендовано Node.js 24 LTS та npm. Наявні допоміжні сценарії збірки розраховані на Linux; у Windows використовуйте WSL. Для них потрібні Bash, GNU timeout, flock і curl.

```bash
git clone https://github.com/OlYermakov/Standpunktprotokoll.git
cd Standpunktprotokoll
npm ci
npm run dev
```

Відкрийте локальну адресу, яку виведе сервер розробки.

## Збірка та перевірки

```bash
npm run build
npm run start
```

Для перевірок PDF потрібен Poppler з командою `pdftotext` (у Debian/Ubuntu: пакет `poppler-utils`).

```bash
npm test
```

## Структура

- `app/` — інтерфейс, локалізація, збереження даних і створення PDF.
- `public/` — іконки, шрифти, PWA-маніфести та service worker.
- `tests/` — перевірки локалізації, PDF і відображення.
- `worker/`, `build/`, `scripts/` — інфраструктура Vinext/Cloudflare Workers.
- `.openai/hosting.json` — конфігурація чинного розміщення Sites; вона не містить облікових даних.

Стек: React, TypeScript, Vinext/Vite, jsPDF, Cloudflare Workers.
